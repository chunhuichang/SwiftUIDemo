# 📘 Week 4 — Animations, Advanced Layouts & UIKit Integration

This is the final week!  
You will learn animations, transitions, custom layouts, and how SwiftUI works with UIKit.

---

## 🎯 Goals
- Understand implicit & explicit animations  
- Use matchedGeometryEffect

- Build your final project
